# stitch-rs Organization Health Repository

This repository contains organization-wide community health files,
standards, and global templates for all repositories hosted under the
[**`stitch-rs`**](https://github.com/stitch-rs) GitHub organization.

## Contents

- [**Organization Profile**](profile/README.md): The official landing
  page and ecosystem map.
- [**Contributing Guidelines**](CONTRIBUTING.md): Engineering standards,
  branching strategy, and pre-PR verification.
- [**Code of Conduct**](CODE_OF_CONDUCT.md): Contributor Covenant standards.
- [**Security Policy**](SECURITY.md): Responsible disclosure and
  vulnerability management.
- [**Issue & PR Templates**](.github/): Canonical issue and pull request
  templates inherited across all organization repositories.
